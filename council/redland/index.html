Redland City Council dog beaches

Queensland · 8 beaches in this tool.

Redland sets the dog rules for North Stradbroke Island (Minjerribah) beaches that it lists, including Home Beach at Point Lookout. Coochiemudlo Main Beach and Russell Island Lions Boulevarde Park use shared hours for migratory birds. Cylinder Beach is prohibited. Main Beach at Point Lookout is managed with the Quandamooka Yoolooburrabee Aboriginal Corporation, so it stays on check with council.
